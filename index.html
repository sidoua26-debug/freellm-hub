🚀 30-Second Quick Start

        
      

      

        

          All providers listed in FreeLLM Hub expose an OpenAI-compatible endpoint. Swap the base_url, paste your API key, and you're good to go!
        


        

          
Fastest route to testing:

          
    
            
  1. Anonymous test (0 seconds signup): Use LLM7.io or OVHcloud directly with any dummy key.
    2. 
            
  2. Generous cloud tier (30 seconds): Grab a free key from Groq (Email only, 30 RPM) or Google Gemini (AI Studio).
    3. 
            
  3. Local / offline: Run ollama run llama3 on your own machine.
    4. 
          

        


        

          
# Universal OpenAI SDK Pattern
from openai import OpenAI

client = OpenAI(
    base_url="https://api.groq.com/openai/v1", # Provider Base URL
    api_key="your-api-key"                    # From Provider Console
)

response = client.chat.completions.create(
    model="llama-3.3-70b-versatile",
    messages=[{"role": "user", "content": "Hello world!"}]
)
print(response.choices[0].message.content)
